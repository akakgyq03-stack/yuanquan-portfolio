# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React, Vite, TypeScript, React Router, CSS Modules; deployed as a static site to Cloudflare Pages through GitHub.

## Users

Recruiters, hiring managers, and interviewers evaluating Yuan Quan for AI product and product-management internships.

## Product Purpose

Present nine projects as a coherent, navigable portfolio. Success means a visitor can understand Yuan Quan's capabilities, open any project directly, move through its evidence, and contact her by email.

## Positioning

The portfolio connects hands-on AIGC creation, AI workflow building, product strategy, UX research, and interaction design through complete project evidence rather than isolated visual mockups.

## Operating Context

Visitors arrive from applications, resumes, direct links, and interviews. They primarily browse on desktop, may open a deep link to one project, and may return to the work index to compare projects.

## Capabilities and Constraints

- One home route and nine project routes.
- Each project has a sticky in-page directory axis with deep links.
- Public email only; no phone number, form, CMS, analytics, authentication, or server functions.
- The Figma page `18:2` is the source of truth. Hidden layers and obvious working boards are excluded.
- Public GitHub repository and free Cloudflare Pages `pages.dev` deployment.

## Brand Commitments

Preserve the typography, dark/light project worlds, artwork, diagrams, spacing character, and bilingual Chinese/English tone in the supplied Figma designs.

## Evidence on Hand

The Figma file contains the approved home, project layouts, copy, screenshots, research diagrams, and artwork. Local workspace projects contain supporting implementation and evaluation imagery for Perfume Lab, Idea Tree, and AIGC work; only exact visual matches may substitute for Figma assets.

## Product Principles

- Let project evidence lead; interface chrome stays quiet.
- Make every project independently shareable and understandable.
- Preserve authored imagery and diagrams without redrawing or substituting them.
- Keep long-form case studies readable at desktop and mobile widths.
- Make navigation state and return behavior predictable.

## Accessibility & Inclusion

Keyboard navigation, visible focus, semantic headings, descriptive image alternatives, reduced-motion support, and WCAG AA text contrast are required.
